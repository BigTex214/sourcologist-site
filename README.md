# sourcologist-site

Static single-page website for [sourcologist.com](https://sourcologist.com) — an independent healthcare recruiting practice specializing in locum tenens placement.

## Stack

- Plain HTML5 with embedded CSS
- Google Fonts (Fraunces, Inter)
- No build step, no JavaScript, no dependencies

## Deployment

Hosted on Cloudflare Pages. Pushes to `main` auto-deploy to production.

## Local preview

Open `index.html` directly in a browser, or serve the directory:

```
python3 -m http.server 8000
```

Then visit http://localhost:8000.
